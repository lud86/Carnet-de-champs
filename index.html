Temps passé

Calculé depuis les journaux d'événements AgOpenGPS (fichiers AgOpenGPS_Events_Log*.txt)

Ces fichiers se trouvent dans le dossier Logs d'AgOpenGPS (à côté du dossier Fields). Ils contiennent une ligne à chaque ouverture/fermeture de champ, avec la date et l'heure — ça permet de calculer combien de temps a été passé sur chaque champ, à chaque session.

Les prix saisis par intervention sont considérés comme des montants hors taxes (HT) — la TVA est calculée et ajoutée automatiquement sur la facture.

Synchronisation multi-appareils (GitHub)

Stocke les données (champs, interventions, types) dans un fichier sur un dépôt GitHub privé, pour les retrouver sur tous tes appareils, y compris ton téléphone. Utilise un dépôt séparé de celui qui héberge l'appli — tes données de facturation ne doivent pas être publiques.
